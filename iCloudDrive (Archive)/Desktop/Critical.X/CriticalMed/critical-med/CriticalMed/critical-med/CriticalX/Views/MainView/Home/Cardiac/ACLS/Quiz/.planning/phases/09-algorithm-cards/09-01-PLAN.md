# Phase 9: Algorithm Cards & Flashcards - Plan

## Objective
Create data models and content for ACLS algorithm cards and flashcards, incorporating all AHA 2025 guideline changes.

## Research Summary: 2025 AHA ACLS Changes

### Key Updates for Algorithm Content

**Medication Changes:**
- Atropine: 1.0 mg initial dose (increased from 0.5 mg) for symptomatic bradycardia
- Calcium: Discontinued routinely during cardiac arrest (only for hyperkalemia, hypocalcemia, CCB toxicity)
- Sodium bicarbonate, magnesium, steroids: Reserved for specific clinical indications only

**New Techniques:**
- Double Sequential Defibrillation (DSD): Two shocks in quick succession from separate defibrillators for refractory VF
- ECPR: Class 2a recommendation for refractory cardiac arrest in equipped systems

**Monitoring Emphasis:**
- ETCO2: Primary non-invasive tool for CPR quality and ROSC detection
- Arterial pressure monitoring in advanced settings

**Vascular Access:**
- IV prioritized over IO in adult cardiac arrest

**Post-ROSC Care:**
- Blood glucose target: 144-180 mg/dL
- Temperature management for all comatose survivors
- Coronary angiography NOT routinely recommended over delayed strategies

**CPR Quality:**
- Compression depth: 2-2.4 inches (max capped at 2.4")
- Rate: 100-120/min
- Ventilation with advanced airway: 1 breath every 6 seconds

**Unified Chain of Survival:**
- Single 6-link chain for all patients (adult/pediatric, in-hospital/out-of-hospital)

## Deliverables

### 1. AlgorithmCard Model
- Card representing a step-by-step ACLS algorithm
- Includes title, steps, decision points, medications, and notes
- Supports branching logic visualization

### 2. FlashCard Model
- Simple front/back study card
- Categories for different ACLS topics
- Difficulty rating for spaced repetition

### 3. Algorithm Card Content (AHA 2025-aligned)
- Cardiac Arrest (VF/pVT) Algorithm
- Cardiac Arrest (PEA/Asystole) Algorithm
- Bradycardia Algorithm
- Tachycardia (Stable) Algorithm
- Tachycardia (Unstable) Algorithm
- Post-ROSC Care Algorithm
- Acute Coronary Syndrome Algorithm
- Stroke Algorithm

### 4. Flashcard Content
- H's and T's (reversible causes)
- Drug doses and indications
- Rhythm recognition key points
- CPR quality metrics

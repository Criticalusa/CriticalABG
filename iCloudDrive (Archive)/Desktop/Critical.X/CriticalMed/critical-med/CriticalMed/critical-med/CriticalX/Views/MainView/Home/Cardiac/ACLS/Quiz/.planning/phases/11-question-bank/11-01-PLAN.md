# Phase 11: Question Bank Population - Plan

## Objective
Create 100+ verified ACLS questions covering all topics with complete explanations, aligned with AHA 2025 guidelines.

## Dependencies
- Phase 5: QuestionBank, Question, Explanation, Reference models
- Phase 10: AHA 2025 Guidelines Summary, Question Template Guide, Content Verification Process

## Deliverables

### 1. ACLSQuestionBank.swift
Static question bank containing 100+ questions organized by topic:
- BLS/CPR Quality: ~15 questions
- VF/Pulseless VT: ~15 questions
- PEA/Asystole: ~12 questions
- Bradycardia: ~12 questions
- Tachycardia (Stable): ~8 questions
- Tachycardia (Unstable): ~8 questions
- Post-ROSC: ~10 questions
- Pharmacology: ~12 questions
- H's and T's: ~8 questions
- Electrical Therapy: ~5 questions
- Airway Management: ~5 questions
- Rhythm Recognition: ~5 questions
- Team Dynamics: ~3 questions
- Vascular Access: ~2 questions

### 2. Question Distribution
- **Difficulty**: 30% Easy, 50% Medium, 20% Hard
- **Format**: 70% Single Choice, 15% Multi-Select, 10% Scenario, 5% True/False/Ordered

### 3. 2025-Specific Questions (REQUIRED)
Must include questions testing these 2025 updates:
- [ ] Atropine 1.0 mg initial dose (not 0.5 mg)
- [ ] IV prioritized over IO in adults
- [ ] Compression depth 2-2.4 inches (max capped)
- [ ] Calcium discontinued routinely in arrest
- [ ] Blood glucose target 144-180 mg/dL post-ROSC
- [ ] Coronary angiography NOT routine post-ROSC
- [ ] Double sequential defibrillation for refractory VF
- [ ] ECPR Class 2a recommendation

## Implementation Steps

### Step 1: Create Question Content File
Create `ACLSQuestionBank.swift` with static question content organized by topic.

### Step 2: Create Explanation Content
Each question has matching explanation with:
- Correct answer rationale
- Why each incorrect answer is wrong
- Key point summary
- Clinical pearls where applicable

### Step 3: Verify Against AHA 2025
Cross-reference all content against:
- AHA-2025-GUIDELINES-SUMMARY.md
- CONTENT-VERIFICATION-PROCESS.md

### Step 4: Add Tests
Add tests to verify:
- Question count >= 100
- All topics covered
- All 2025 updates included
- No duplicate IDs
- All questions have valid structure

## Success Criteria
- [ ] 100+ questions created
- [ ] All 16 ACLSTopic categories covered
- [ ] All 2025 updates tested
- [ ] Difficulty distribution: 30/50/20
- [ ] Complete explanations for all questions
- [ ] Tests pass
